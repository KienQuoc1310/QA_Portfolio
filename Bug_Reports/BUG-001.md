# BUG-001 — Checkout Total Is Calculated Incorrectly

## 1. Bug Information

| Field | Value |
|---|---|
| Bug ID | BUG-001 |
| Module | Checkout |
| Related Test Case | TC-CHK-023 |
| Severity | High |
| Priority | High |
| Environment | Web |
| Browser | Chrome |
| Platform | Windows |
| Status | New |
| Reproducibility | 100% |

---

## 2. Summary

Checkout displays an incorrect final order total when the order contains multiple products and a shipping fee.

---

## 3. Preconditions

- User is able to access the E-commerce Web Application.
- Products are available.
- User has added multiple products to the cart.
- A valid shipping method is available.
- The shipping fee is defined by the selected shipping method.

---

## 4. Test Data

| Item | Value |
|---|---:|
| Product A | $100 × 2 |
| Product B | $50 × 1 |
| Subtotal | $250 |
| Shipping | $20 |
| Expected Total | $270 |
| Actual Total | $290 |

---

## 5. Steps to Reproduce

1. Open the E-commerce Web Application.
2. Open Product A.
3. Add 2 units of Product A to the Cart.
4. Open Product B.
5. Add 1 unit of Product B to the Cart.
6. Open the Cart.
7. Click Checkout.
8. Enter valid customer information.
9. Enter valid shipping information.
10. Select the shipping method with a $20 shipping fee.
11. Review the order summary.

---

## 6. Expected Result

The final total should be calculated according to:

Subtotal + Shipping

Therefore:

$250 + $20 = $270

The Checkout page should display:

**Total = $270**

---

## 7. Actual Result

The Checkout page displays:

**Total = $290**

The system adds an additional $20 to the expected total.

---

## 8. Reproducibility

The issue can be reproduced consistently using the same test data.

Reproduction rate:

**5/5 attempts**

---

## 9. Impact

The incorrect total causes the customer to see a price higher than the expected order amount.

This can result in:

- Incorrect customer charges.
- Customer trust issues.
- Incorrect order records.
- Financial discrepancies.

---

## 10. Evidence

Evidence should be attached here:

- Screenshot of the Checkout order summary.

---

## 11. Suggested Investigation Area

Check the Checkout total calculation logic, especially the handling of:

- Cart subtotal.
- Shipping fee.
- Multiple products.
- Shipping fee being added more than once.
