# BUG-004 — Cart Allows Quantity Higher Than Available Stock

## 1. Bug Information

| Field | Value |
|---|---|
| Bug ID | BUG-004 |
| Module | Cart |
| Related Test Case | TC-CART-014 |
| Severity | High |
| Priority | High |
| Environment | Web |
| Browser | Chrome |
| Platform | Windows |
| Status | New |
| Reproducibility | 100% |

---

## 2. Summary

The Cart allows users to set a product quantity higher than the currently available stock.

---

## 3. Preconditions

- Product is available.
- Product stock is 10 units.
- User can add the product to Cart.
- User can manually update the product quantity.

---

## 4. Requirement / Business Rule

The maximum quantity that a user can purchase must not exceed the currently available stock.

For this test:

Available Stock = 10

Therefore:

Minimum Quantity = 1
Maximum Quantity = 10

---

## 5. Test Data

| Test Data | Value |
|---|---:|
| Product | Product A |
| Available Stock | 10 |
| Current Cart Quantity | 1 |
| Attempted Quantity | 11 |

---

## 6. Boundary Analysis

| Quantity | Classification | Expected |
|---:|---|---|
| 0 | Below minimum | Invalid |
| 1 | Minimum boundary | Valid |
| 2 | Valid partition | Valid |
| 9 | Valid partition | Valid |
| 10 | Maximum boundary | Valid |
| 11 | Above maximum | Invalid |

---

## 7. Steps to Reproduce

1. Open the E-commerce Web Application.
2. Open Product A.
3. Verify that Product A has 10 units available.
4. Add Product A to the Cart.
5. Open the Cart.
6. Change the product quantity from 1 to 11.
7. Click Update Cart.

---

## 8. Expected Result

The application should reject quantity 11 because the available stock is only 10 units.

The user should receive an appropriate validation message.

The Cart should not contain more than 10 units of the product.

---

## 9. Actual Result

The application accepts quantity 11.

The Cart displays:

Quantity = 11

The user can continue toward Checkout with a quantity greater than the available stock.

---

## 10. Reproducibility

The issue can be reproduced consistently.

Reproduction rate:

5/5 attempts.

---

## 11. Impact

The system can allow users to attempt purchasing more units than are available.

This may cause:

- Incorrect inventory calculations.
- Checkout failures.
- Incorrect order quantities.
- Inventory inconsistencies.
- Poor customer experience.
