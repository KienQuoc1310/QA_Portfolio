# BUG-002 — Checkout Allows Order Submission Without Required Phone Number

## 1. Bug Information

| Field | Value |
|---|---|
| Bug ID | BUG-002 |
| Module | Checkout |
| Related Test Case | TC-CHK-006 |
| Severity | High |
| Priority | High |
| Environment | Web |
| Browser | Chrome |
| Platform | Windows |
| Status | New |
| Reproducibility | 100% |

---

## 2. Summary

Checkout allows the user to submit an order without providing the required phone number.

---

## 3. Preconditions

- User can access the E-commerce Web Application.
- Cart contains at least one available product.
- User can access the Checkout page.
- Phone number is defined as a required field.

---

## 4. Test Data

| Field | Value |
|---|---|
| Customer Name | Nguyen Van A |
| Phone Number | Empty |
| Email | test@example.com |
| Address | 123 Example Street |
| Shipping Method | Standard Shipping |
| Payment Method | Supported payment method |

---

## 5. Steps to Reproduce

1. Open the E-commerce Web Application.
2. Add an available product to the Cart.
3. Open the Cart.
4. Click Checkout.
5. Enter a valid customer name.
6. Leave the Phone Number field empty.
7. Enter a valid email address.
8. Enter a valid shipping address.
9. Select a valid shipping method.
10. Select a valid payment method.
11. Submit the order.

---

## 6. Expected Result

The application should prevent order submission.

A validation message should indicate that the Phone Number field is required.

No order should be created.

---

## 7. Actual Result

The application allows the order to be submitted even though the required Phone Number field is empty.

An order is created successfully without a phone number.

---

## 8. Reproducibility

The issue can be reproduced consistently.

Reproduction rate:

**5/5 attempts**

---

## 9. Impact

The system can create orders with incomplete customer information.

This may cause:

- Difficulty contacting customers.
- Incomplete order records.
- Problems during delivery.
- Potential operational issues for customer support.
