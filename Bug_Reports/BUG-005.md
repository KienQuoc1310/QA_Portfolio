
# BUG-005 — Order Is Confirmed After Payment Failure

## 1. Bug Information

| Field | Value |
|---|---|
| Bug ID | BUG-005 |
| Module | Checkout / Payment / Order |
| Related Test Cases | TC-CHK-031, TC-PAY-008 |
| Severity | Critical |
| Priority | Critical |
| Environment | Web |
| Browser | Chrome |
| Platform | Windows |
| Status | New |
| Reproducibility | 100% |

---

## 2. Summary

The system changes the Order status to Confirmed even though the payment transaction has failed.

---

## 3. Preconditions

- User has a valid account.
- Cart contains an available product.
- Checkout information is valid.
- A payment method capable of returning a failed transaction is available.
- Order can be created from Checkout.

---

## 4. Business Rule

An Order must not be confirmed when its payment transaction fails.

Expected state flow:

Cart
→ Pending Payment
→ Payment Failed
→ Pending Payment / Payment Failed

The Order must not transition to:

Payment Failed
→ Confirmed
