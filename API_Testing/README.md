# API Testing

## 1. Overview

This section contains API testing documentation for the QA Portfolio.

The purpose is to demonstrate the ability to:

- Understand HTTP and REST APIs.
- Create and execute API test cases.
- Validate API requests and responses.
- Validate HTTP status codes.
- Validate response headers.
- Validate JSON response bodies.
- Validate response data.
- Test authentication and authorization.
- Test positive and negative scenarios.
- Test boundary and invalid input.
- Validate relationships between API responses and business rules.
- Use Postman for API testing.
- Use API test data to support database validation.
